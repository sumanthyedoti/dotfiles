# .dotfiles project overview
- Purpose: Personal dotfiles repository for shell, tmux, Neovim, X11/XMonad, SSH, Git, and related workstation configuration.
- Platform: Linux-oriented, with some macOS notes in README.
- Tech stack: Mostly configuration files and scripts; languages/configs include shell rc files, tmux config, Lua/Neovim config, XMonad config, Git config, SSH config, and assorted dot-config directories.
- Structure: top-level dotfiles like `.tmux.conf`, `.bashrc`, `.zshrc`, `.vimrc`, `.gitconfig`; larger app configs under `.config/`; wallpapers under `wallpapers/`.
- Package manifest: minimal `package.json` with a `shadcn` dev dependency, but this is not the primary workflow for the repo.
